真诚执着 // 有梦敢追

我叫李凌宇，14岁，在贵阳市云岩实验中学读初三。做事比较认死理，认定的事会坚持到底。平时容易想得多，但也让我对细节更在意。喜欢有设计感的东西，不管是车、照片还是飞机，觉得美本身就有力量。

课余时间大多花在拍照和看车上。用Nikon Z50扫街拍夜景，看车展研究参数，刷J-20的试飞视频。目标是考上985、开上RS6、带着相机去更多地方。计划常做一大堆，执行总打折扣，正在慢慢改。
